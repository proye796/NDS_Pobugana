## 알려진 제한

- **프리징(멈춤) 가능성이 있습니다.** 한글로 다시 그린 그림 일부가 일본판보다 텍스처 메모리를 더 씁니다(그래픽 파일 14개, 최대 약 7.5KB: 정보 화면, 란세 지도, 통신 화면, 성 지도, 전투 지도 등). 일본판에서도 여유가 적은 화면에서 창을 새로 열 때 메모리가 모자라면 게임이 멈출 수 있습니다.
  - 보고된 위임 메뉴의 멈춤은 고쳤고, 실행해서 확인했습니다.
  - 같은 원인이 걱정되는 성 지도의 금액(500/1000/2000) 선택 메뉴와 아이템 선택 창은 미리 메모리 사용을 줄였습니다.
  - 아직 실행해서 확인하지 못한 화면: 성 지도의 포니기리 상점 목록, 성 지도의 특성·수치 선택 목록, 란세 지도에서 여는 아이템 선택 창(일본판보다 여유가 약 4.6~4.9KB 적음).
  - 멈추는 화면을 만나면 화면 이름과 직전 조작을 알려 주세요. 진행하기 전에 자주 저장하는 것을 권장합니다.
- 오프닝 영상은 다시 압축했기 때문에 움직임이 큰 장면(약 5초·38초·43초)에서 블록 자국이 보일 수 있습니다. 재생 중 틱틱·드드득 하는 소리는 일본판에서도 납니다.
